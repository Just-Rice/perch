Add Perch to your authenticator app

Each time you connect, Perch asks for a 6-digit code from this app as well as your passkey, so a lost phone or a guessed password is never enough on its own.

Any authenticator app works: Apple Passwords, Google Authenticator, Microsoft Authenticator, 1Password and others.

✓Set up

New phone or new app? Replace it. The old codes keep working until the new one is confirmed.

  1. Open your authenticator app and add a new account (often a + button).
  2. Scan this code with it.
  3. Type the 6-digit code the app shows, then press Confirm.

Pair a device

Pairing lets your phone, tablet or another computer connect to this Mac. Do it once for each device.

Finish step 2 first: every sign-in needs a code from your authenticator app.

Perch shows a code to scan with the device you want to use.

Only scan this with your own device. Never send this code or link to anyone — whoever uses it can control this Mac.
  1. On your device, scan this code with the camera, or open the link below in its browser.
  2. It asks for Face ID, Touch ID or its screen lock, to make a passkey for this Mac.
  3. Then it asks for the 6-digit code from your authenticator app.

    Show your screen to someone optional

    School or office Wi-Fi optional

    Some networks block the direct connection Perch normally uses. A relay passes the connection through Cloudflare instead, over the same route as ordinary websites.

    I run this relay service

    Type the service's owner key on each of your own Macs. They then have no 20 GB limit, only the service's overall one, and this card shows everyone's use.

    Or a relay of your own

    Set it up once, in your own Cloudflare account: free for the first 1,000 GB each month, which is hundreds of hours of use. It is used instead of the shared relay.

    Status: Not set up

    How to get a relay key (about 5 minutes)
    1. Sign up or sign in at dash.cloudflare.com (a free account is enough).
    2. In the menu, open Realtime (it may be called Calls), then TURN Server.
    3. Choose Create, give it a name such as Perch, and create it.
    4. Cloudflare shows a Turn Token ID and an API Token. Copy both into the boxes below. The API token is shown only once; if you lose it, create a new key.

    Perch keeps the token in this Mac's Keychain and only uses it to ask Cloudflare for short-lived relay logins for each connection.

    Relay without a card optional

    Another way through strict Wi-Fi: a small relay you run in your own free Cloudflare account, as a Worker. It needs no payment details and has no monthly data allowance to use up. It only passes along encrypted data: it can't see your screen. If both relays are set up, the one above is tried first.

    Status: Not set up

    How to set up the relay (about 5 minutes, needs Node.js)
    1. Sign up or sign in at dash.cloudflare.com (a free account is enough).
    2. On any computer with Node.js, open Terminal and run: 
      git clone https://github.com/Just-Rice/perch
cd perch/relay
npx wrangler login
npx wrangler deploy
    3. Wrangler prints the relay's address, such as https://perch-relay.your-name.workers.dev. Paste it below.

    The first Mac to save a relay becomes its owner; no other Mac can use it. For a second Mac, deploy another copy under a different name (change name in relay/wrangler.toml).

    If the Perch website or the public message services are blocked where you are, the relay stands in for both: add its address under Sites that can sign in, pair your device on that site once, and sign in at the relay's address from then on.

    Perch keeps the relay's secret in this Mac's Keychain.

      Add a site

      Only add a site you run yourself or trust completely. Whoever controls that site can see what you type there, including your codes and backup password, and can control this Mac while you are signed in. Never add a site because someone asked you to.

      Passkeys belong to one site each, so pair your devices again on the new site (step 3, choosing that site).

        Give this Mac a new name

        Your devices keep working. The backup password is removed, because it goes with the name.

        Choose your own name (not recommended)

        A name Perch makes up is one of about 590 million, so nobody can guess it. One you choose is much easier to guess. Anyone who guesses it can try the backup sign-in (they still need the backup password and a 6-digit code, and wrong tries are slowed down), and the Mac answers them. Passkey sign-ins don't use the name.

        Start over

        Forget everything: this Mac gets a new name and new keys, every device is removed and you set Perch up again from step 1.
