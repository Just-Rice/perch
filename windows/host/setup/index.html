      Sign-in & security

      How your devices prove it's you: a passkey, a 6-digit code, and a backup password if you need one.

      Authenticator app

      Each time you connect, Roost asks for a 6-digit code from this app as well as your passkey, so a lost phone or a guessed password is never enough on its own.

      Optional now: no 6-digit code is asked for anywhere (see When to ask for the 6-digit code). Set it up if you want codes back.

      Any authenticator app works: Microsoft Authenticator, Google Authenticator, Apple Passwords, 1Password and others.

      Set up New phone or new app? Replace it. The old codes keep working until the new one is confirmed.
      1. Open your authenticator app and add a new account (often a + button).
      2. Scan this code with it.
      3. Type the 6-digit code the app shows, then press Confirm.

      Can't scan it? Choose to enter a setup key in the app and type this:

      Account: · Time-based

      When to ask for the 6-digit code

      Each switch adds the code to that way in. Off is quicker and less safe: whoever has the passkey, the backup password or a pairing link gets in with nothing else. Wrong tries still lock sign-in for a while.

      Choose a password

      Your password never leaves this page: Roost keeps only a scrambled check of it that can't be turned back into the password. So Roost can't show it to you again: save it in your password manager or write it down.

      Sites that can sign in Advanced

      Your PC only accepts sign-ins made on these sites. The official Roost site is always on the list. Add another only if you run your own copy of the Roost website.

        Add a site
        Only add a site you run yourself or trust completely. Whoever controls that site can see what you type there, including your codes and backup password, and can control your PC while you are signed in. Never add a site because someone asked you to.

        Passkeys belong to one site each, so pair your devices again on the new site (under Devices, choosing that site).

        School or office Wi-Fi

        Some networks block direct connections. A relay passes the connection through Cloudflare instead, over the same route as ordinary websites. It only carries encrypted data: it can't see your screen. Set up either one, or both: the TURN relay is tried first.

        Cloudflare TURN relay Optional

        Set up once in your own Cloudflare account: free for the first 1,000 GB each month, which is hundreds of hours. Cloudflare may ask for a payment card for this one; the Worker relay below doesn't.

        Not set up

        Status: Not set up

        How to get a relay key (about 5 minutes)
        1. Sign up or sign in at dash.cloudflare.com (a free account is enough).
        2. In the menu, open Realtime (it may be called Calls), then TURN Server.
        3. Choose Create, give it a name such as Roost, and create it.
        4. Cloudflare shows a Turn Token ID and an API Token. Copy both into the boxes below. The API token is shown only once; if you lose it, create a new key.

        Roost keeps the token on your PC, encrypted with your Windows account, and only uses it to ask Cloudflare for short-lived relay logins for each connection.

        Worker relay, no card needed Optional

        A small relay you run in your own free Cloudflare account, as a Worker. No payment details, no monthly data allowance to use up.

        Not set up

        Status: Not set up

        How to set up the relay (about 5 minutes, needs Node.js)
        1. Sign up or sign in at dash.cloudflare.com (a free account is enough).
        2. On any computer with Node.js, open a terminal (PowerShell on Windows) and run: 
          git clone https://github.com/Just-Rice/perch
cd perch/windows/relay
npx wrangler login
npx wrangler deploy
        3. Wrangler prints the relay's address, such as https://roost-relay.your-name.workers.dev. Paste it below.

        The first PC to save a relay becomes its owner; no other PC can use it. For a second PC, deploy another copy under a different name (change name in relay/wrangler.toml).

        If the Roost website or the public message services are blocked where you are, the relay stands in for both: add its address under Sites that can sign in, pair your device on that site once, and sign in at the relay's address from then on.

        Roost keeps the relay's secret on your PC, encrypted with your Windows account.

        If the Worker relay is down

        A copy of the relay running on a computer that stays on (relay/node in Roost's source), started with the Worker relay's secret. Your PC uses it only when the Worker can't be reached, for example after a day's free allowance is used up.

        Control admin apps

        Windows keeps ordinary apps away from apps that run as administrator. Without this, Roost can't click or type into Task Manager, installers or admin tools, and can't show Windows' "Do you want to allow…" prompts (UAC).

        Rename, start over or uninstall

        Bigger changes. Each one asks you to confirm first.

        Give your PC a new name

        Your devices keep working. The backup password is removed, because it goes with the name.

        Choose your own name (not recommended)

        A name Roost makes up is one of about 590 million, so nobody can guess it. One you choose is much easier to guess. Anyone who guesses it can try the backup sign-in (they still need the backup password and a 6-digit code, and wrong tries are slowed down), and your PC answers them. Passkey sign-ins don't use the name.

        Start over

        Forget everything: your PC gets a new name and new keys, every device is removed and you set Roost up again from the start.
